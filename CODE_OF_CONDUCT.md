# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and considerate. Assume good intent and critique ideas, not people.
- Harassment, personal attacks, discriminatory language and publishing others' private information are not acceptable.
- Give and accept technical feedback gracefully; security reviews in particular should be direct about the problem and kind to the author.

This applies in issues, pull requests, discussions and any other project space.

## Reporting

Report unacceptable behaviour to the maintainer privately through their GitHub profile ([@YashkantG](https://github.com/YashkantG)). Reports are handled confidentially. Maintainers may remove comments, close threads or block participants who break these rules.
